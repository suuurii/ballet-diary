# 芭蕾手账 🩰

一个给自己用的芭蕾练习记录 App（网页应用 PWA），可在 iPhone 上像 App 一样使用。

## 目前能做什么（第一阶段）

- **记录练习时长**：手机计时器（开始 / 暂停 / 结束）、手动补录
- **导入 iWatch 的 Barre 记录**：从 iPhone「健康」App 导出数据文件，导入后自动提取
- **课程分类打标**：零基础 / 初级 / 中级 / 技巧 / 软开 / 舞姿 / 基础素质，可自定义增删改名
- **统计可视化**：打卡日历热力图、月度汇总 + 分类构成（一张图）、分类占比、练习趋势（按周）
  - 图表可自定义显示 / 隐藏，尽量合并（一张图表达多个意思）
- **数据备份**：导出 / 导入 JSON 文件（防丢数据，也是将来迁移的通道）

## 怎么在电脑上预览

1. 打开「终端」，进入本项目文件夹：
   ```bash
   cd "/Users/shuyingxu/Documents/00_Vibe Coding/Ballet"
   ```
2. 安装依赖（首次，需联网；已配置国内镜像源）：
   ```bash
   npm install
   ```
3. 启动：
   ```bash
   npm run dev
   ```
4. 用浏览器打开终端里显示的地址（通常是 http://localhost:5173），即可使用。

## 怎么放到 iPhone 上用

数据存在手机浏览器本机，所以需要一个网址。推荐用免费的 Vercel：

1. 注册两个免费账号：[GitHub](https://github.com) 和 [Vercel](https://vercel.com)（用 GitHub 账号登录 Vercel 即可）
2. 把本项目推送到 GitHub
3. 在 Vercel 里「Add New Project」导入这个仓库，框架选 Vite，直接 Deploy
4. 部署成功后得到一个网址，用 iPhone 的 Safari 打开 → 「分享」→「添加到主屏幕」，就变成一个像 App 的图标

> 更省事的做法：让 Claude 帮你执行 `npx vercel` 部署（需要你登录 Vercel）。

## 重要：数据备份

数据存在手机浏览器本机（不联网）。**建议定期在「设置」页点「导出数据」保存一份 JSON 备份**，因为：

- 浏览器可能在长期不使用时清理本地数据
- 将来升级或迁移时，用「导入数据」即可恢复

## 技术说明（供参考）

- React + Vite + TypeScript，纯前端、无后端
- 本地数据库：IndexedDB（Dexie.js）
- 图表：ECharts
- 健康数据解析：jszip
- 数据存本机，不上传任何服务器
