# 云备份 · 一次性搭建说明

这一份是给**不是程序员**的人看的：照着点，大约 10 分钟。
做完之后，你手机上每次记完一笔，几秒钟后会自动传一份备份到云端。

```
手机（浏览器）  ──HTTPS──▶  Cloudflare Worker  ──▶  R2 存储桶（只有你能读）
    恢复码                       算成一段乱码
```

---

## 一、注册 Cloudflare

1. 打开 <https://dash.cloudflare.com/sign-up>
2. 填邮箱 + 密码，注册（免费，国内邮箱也能用）
3. 去邮箱点验证链接

> 如果后面开 R2 时它要你**绑一张银行卡**：那是 Cloudflare 的规矩，用来防止滥用。
> 10 GB 以内**不会扣钱**，只是登记一下。绑不了的话告诉我，我们换别的地方存。

## 二、建一个存储桶

1. 左边菜单找 **R2 Object Storage**（可能需要先点「Enable R2」开通）
2. 点 **Create bucket**
3. 名字随便起，比如 `ballet-backup`
4. 位置选 **Automatic** 就行
5. 创建完**不用**开公开访问，保持私有

## 三、建 Worker（把备份收进来）

1. 左边菜单 **Workers & Pages** → **Create** → 选 **Worker** → **Deploy**
2. 起个名字，比如 `ballet-backup`
3. 部署完点 **Edit code**（或 *</>* 图标），把里面的示例代码**全部删掉**
4. 打开本仓库的 `worker/backup-worker.js`，把**整份内容**复制进去
5. 点右上角 **Deploy**

## 四、把存储桶接给 Worker

1. 在 Worker 页面点 **Settings** → **Bindings**（有的界面叫 *Variables and Secrets* / *Bindings*）
2. **Add** → 选 **R2 bucket**
3. 变量名（Variable name）**必须**填：`BACKUP` ← 大小写完全一致
4. 存储桶选你在第二步建的那个 `ballet-backup`
5. 保存 / 重新部署

## 五、把地址填回网页

1. Worker 页面顶部的网址长这样：`https://ballet-backup.你的名字.workers.dev`
2. 打开 `src/lib/cloudConfig.ts`，把它填进引号里：
   ```ts
   export const BACKUP_API = 'https://ballet-backup.你的名字.workers.dev'
   ```
3. 重新部署网页

## 六、在手机上开起来

1. 打开手账 → 齿轮 → **自动云备份** → 开启
2. 屏幕上会出现一串 `BAL-XXXXX-XXXXX-XXXXX-XXXXX`
3. **抄在纸上，或截图存进相册**——它是唯一的钥匙，服务器不保存它
4. 看到「云备份已打开，第一份传好了」就成了

以后换手机：设置 → 自动云备份 → 「换手机了？用恢复码还原」，输入那串码，全部记录回来。

---

## 它到底安全吗

- 服务器**不保存恢复码**，只保存它的哈希（一串不可反推的乱码）当文件夹名。
  就算整桶备份被人拿走，也看不出这是谁的。
- 传输走 HTTPS，别人截不到。
- 恢复码是 20 位、约 100 位随机——猜中的概率比连续中两次彩票还低。
- **风险只剩一个：你自己把恢复码弄丢了**，那云端那份就再也打不开了（手账本身还在手机上，不受影响）。

## 每月花多少钱

R2 免费额度 10 GB。一份带几千张照片的备份压缩后也就几十 MB，按月覆盖、只留最近 5 份，
正常情况下**永远在免费额度内**。Worker 免费额度每天 10 万次请求，你一天最多用几十次。
